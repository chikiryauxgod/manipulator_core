# Платформа

Здесь прикладные интерфейсы подключаются к STM32 и FreeRTOS. Драйверы работают с периферией, а задачи передают приложению готовые запросы.

- `stm32/drivers/` — USART2, TIM2, GPIO, Flash и источник времени HAL.
- `freertos/` — задачи приложения и транспорт RTU.

UART: PA2 — TX, PA3 — RX; TX адаптера подключается к PA3, RX — к PA2, земля общая. Уровни — 3.3 В, штатный режим — 115200, 8E1.
